# Meta-CyberIDS Framework

## Introduction

This repository provides a meta-learning-based framework for network intrusion detection. The model is designed to adapt effectively to diverse datasets with varying class distributions and features. Follow the steps below to process the data and train the model.

---

## Steps to Run the Project

1. **Download Data**  
   Download the datasets from data.txt.

2. **Execution Order**  
   For each dataset, execute the following steps in order:
   - **data_split**: Run the script to split the dataset.
   - **data_preprocessing**: Run the notebook to preprocess the data.
   - **{models}.ipynb**: Train models using the jupyter notebook.
